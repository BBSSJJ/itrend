# Plans

작은 변경은 대화 중 계획으로 충분하다. 여러 구성요소를 건드리거나 한 번에
끝나지 않는 작업은 구현 전에 이 디렉터리에 실행 계획을 작성한다.

실행 계획에는 다음을 포함한다.

- 해결할 사용자 문제와 범위
- 현재 동작을 확인한 근거
- 단계별 구현 및 검증 방법
- 중요한 결정과 변경 이유
- 완료 조건과 남은 후속 작업

활성 계획은 `active-<topic>.md`, 완료 후 보존할 가치가 있는 계획은
`completed-<topic>.md`로 명명한다. 알려진 작은 결함과 기반 작업은
`tech-debt.md`에서 관리한다.
