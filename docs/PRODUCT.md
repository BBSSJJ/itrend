# Product

## 목적

ITrend는 여러 출처에 흩어진 IT 이슈와 기술 콘텐츠를 한곳에 모으고, AI가
콘텐츠의 주제를 태그와 요약으로 구조화하여 사용자가 관심 있는 내용을 빠르게
발견하도록 돕는다.

## 초기 사용자

현재 가정하는 사용자는 최신 기술 동향을 효율적으로 확인하려는 개발자와 IT
관심자다. 실제 사용을 시작한 뒤 이 가정은 사용자 피드백으로 검증한다.

## 핵심 사용자 흐름

1. 시스템이 등록된 RSS 및 공개 API에서 새 기사를 수집한다.
2. 중복 기사를 제거하고 원문 메타데이터를 저장한다.
3. AI가 제목과 설명을 바탕으로 일관된 기술 태그를 생성한다.
4. 사용자는 최신 기사 목록을 보고 인기 태그로 필터링한다.
5. AI가 제목과 설명을 근거로 만든 짧은 요약으로 원문을 열기 전에 핵심 내용을
   파악한다.

## 현재 범위

- RSS, Hacker News, Dev.to 수집
- URL 기준 중복 방지
- 폐쇄형 canonical 목록을 사용하는 Groq LLM 태깅, 고정밀 별칭 선태깅과
  키워드 기반 대체 처리
- 수집된 제목과 설명만을 근거로 하는 500자 이내의 한국어 AI 요약. 설명의 정보량에
  맞춰 배경·핵심 접근·결과 또는 의미를 필요한 만큼 간결하게 제공
- 출처가 표시된 기사 목록 조회, 태그 필터, 페이지네이션
- 제목 아래 요약 표시 및 AI가 생성한 요약을 구분하는 `AI 요약` 배지
- 로컬 PostgreSQL 기반 개발

## 다음 제품 단계

- 기사 본문을 안전하게 수집해 요약 근거를 보강하는 흐름
- 신뢰할 수 있는 자동 수집 스케줄
- 실패 재시도와 수집 상태 관찰
- 외부 배포 환경 및 운영 안전장치

## 제품 원칙

- 원문 링크와 출처를 명확히 유지한다.
- AI가 생성한 태그와 요약은 원문 사실을 왜곡하지 않아야 한다.
- AI 또는 외부 소스 장애가 기존 기사 조회를 막아서는 안 된다.
- 중복보다 누락과 오분류를 관찰할 수 있는 구조를 우선한다.
- 비밀 키는 코드나 문서에 저장하지 않는다.

## 현재 비목표

- 원문 전체를 ITrend 콘텐츠로 재게시하는 것
- 사용자 계정, 개인화 추천, 결제
- 배포 플랫폼을 조기에 고정하는 것

범위가 달라지면 기능 구현 전에 이 문서를 먼저 갱신한다.
